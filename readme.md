This was tested on the aviary system.

Instructions:

1. Extract the contents of the zip file into a single directory.
2. Edit the auth.cfg file with your credentials. 
3. Compile the files by typing 'make' into the terminal in that directory.
4. Populate database by typing 'make rundb' or 'java -cp .:mssql-jdbc-11.2.0.jre18.jar PopulateDB' in the terminal.
5. Run interface by typing 'make run' or 'java -cp .:mssql-jdbc-11.2.0.jre18.jar PokemonInterface' in the terminal.
